# لوکس بلوم | Luxe Bloom Cosmetics 🌸
### فروشگاه آنلاین محصولات آرایشی، بهداشتی و عطرهای نیش فاخر

پیاده‌سازی کامل و جامع فروشگاه آنلاین بر اساس طراحی **Google Stitch** (شناسه پروژه: `5452763928037950496`) با استفاده از **Next.js 14 (App Router)**، **Tailwind CSS** و هماهنگی کامل با استاندارد‌های طراحی راست‌به‌چپ (RTL).

---

## ✨ ویژگی‌های کلیدی پروژه

1. **طراحی وفادار به بوم Google Stitch (Pixel-Perfect Fidelity)**:
   - بازتولید دقیق سیستم طراحی Luxe Bloom با پالت رنگی اختصاصی (داستی رز `#8a4853`، سطوح آلاباستر `#f9f9fc`، و خاکستری متالیک `#1a1c1e`).
   - چیدمان native راست‌به‌چپ (RTL) متناسب با تایپوگرافی فارسی.

2. **صفحات اصلی پیاده‌سازی شده**:
   - **صفحه اصلی (`/`)**: بنر هیرو ادیتوریال، گرید نیازهای زیبایی، پیشنهادات شگفت‌انگیز با **تایمر شمارش معکوس زنده**، تب‌های دسته‌بندی پرفروش‌ترین‌ها و مجله زیبایی.
   - **کاتالوگ محصولات (`/catalog`)**: سایدبار فیلترینگ چندمعیاره (برندهای دیور، هدی بیوتی، استی لادر، فنتی بیوتی، نوع پوست، اسلایدر قیمت)، کارت‌های اشرافی و انتخاب آنلاین رنگ (Shade Swatch).
   - **جزئیات محصول دیور (`/product`)**: گالری با پیش‌نمایش بزرگ‌نمایی، انتخابگر ۵ تناژ رنگی (Shade Picker)، انتخاب حجم (۳۰ و ۵۰ میل)، تنظیم تعداد، تب‌های ترکیبات و نحوه مصرف، و اسلایدر محصولات مکمل.
   - **سبد خرید و تسویه‌حساب (`/checkout`)**: مدیریت پویا و بلادرنگ اقلام سبد خرید، محاسبه خودکار تخفیف و ارسال رایگان، فرم کوپن تخفیف، و محصولات پیشنهادی لحظه خرید (Cross-Sell).
   - **ورود و ثبت‌نام اعضا (`/login`)**: احراز هویت امن دوگانه شامل ورود سریع با پیامک یکبار مصرف (OTP با تایمر ۱۲۰ ثانیه‌ای و تفکیک ۵ رقمی)، ورود با ایمیل و پسورد، ورود با حساب‌های گوگل و اپل، و هماهنگ با دیزاین سیستم لوکس بلوم.

3. **مدیریت وضعیت سراسری (Cart State Management)**:
   - پیاده‌سازی شده با React Context (`CartContext`) برای افزودن، حذف، تغییر تعداد، محاسبه تخفیف و نمایش وضعیت در تمام صفحات و هدر سایت.

## 🛠 پشته فناوری (Tech Stack)

- **فریم‌ورک**: [Next.js 14](https://nextjs.org/) (App Router)
- **محیط کاربری**: [React 18](https://react.dev/)
- **استایل‌دهی**: [Tailwind CSS](https://tailwindcss.com/)
- **فونت و تایپوگرافی**: [Vazirmatn](https://github.com/rastikerdar/vazirmatn) + Google Noto Serif & Noto Sans
- **آیکون‌ها**: Google Material Symbols Outlined
- **منبع دیزاین سیستم**: Google Stitch Canvas

## 🚀 راهنمای نصب و راه‌اندازی محلی

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm یا yarn یا pnpm

### گام‌های اجرا

۱. کلون کردن مخزن:
```bash
git clone https://github.com/alifiroozii/luxe-bloom-cosmetics.git
cd luxe-bloom-cosmetics
```

۲. نصب وابستگی‌ها:
```bash
npm install
```

۳. اجرای سرور توسعه:
```bash
npm run dev
```

یا ساخت نسخه بهینه تولید (Production Build):
```bash
npm run build
npm run start
```

سپس در مرورگر به آدرس `http://localhost:3000` مراجعه فرمایید.

## 📄 ساختار پوشه‌بندی

```
├── public/                 # دارایی‌های عمومی، لوگو و تصاویر
├── src/
│   ├── app/
│   │   ├── layout.jsx      # چیدمان سراسری، هدر و فوتر
│   │   ├── globals.css     # استایل‌های پایه و تایپوگرافی
│   │   ├── page.jsx        # صفحه اصلی فروشگاه
│   │   ├── catalog/        # صفحه کاتالوگ و لیست محصولات
│   │   ├── product/        # صفحه جزئیات محصول دیور
│   │   └── checkout/       # صفحه سبد خرید و تسویه‌حساب
│   ├── components/
│   │   ├── Header.jsx      # هدر ناوبری، جستجو و سبد
│   │   ├── Footer.jsx      # فوتر ادیتوریال و نمادهای اعتماد
│   │   └── Toast.jsx       # اعلان‌های ثبت در سبد خرید
│   └── context/
│       └── CartContext.jsx # مدیریت وضعیت سبد خرید
├── tailwind.config.js      # توکن‌های رنگی و اندازه‌گیری Stitch
└── package.json
```
